# V25.3f – internal surrender and disconnect rules

Prototype rules: a trusted admission boundary must enable monitoring before the first round after both players join. Participant heartbeats are bound to verified identity, throttled to one per 5 seconds; recommended client cadence 10 seconds. At 45 seconds without heartbeat, server tick/command adjudicates absence: one absent player forfeits, both absent void the game. An ordinary round can finish before the grace expires; no automatic timer exists yet. An authenticated participant may surrender only for themselves. All state-changing events are recorded in the private journal and survive restarts. Forfeit scores are adjusted only if needed to ensure the non-forfeiting player leads under the existing score-derived settlement schema; original scores and termination reason are retained in the journal. No extra ELO penalty. Ordinary lack of correct answers is not proof of AFK; a heartbeat indicates presence, not gameplay effort. This is not deployed or exposed to HTTP. Authenticated admission, heartbeat transport, reliable server scheduling, infrastructure outage protection, anti-abuse limits, and D1 Preview integration must be implemented and tested before enabling ranked. No migration change. Node 22.13+ needed for SQLite integration tests.
