# V25.3b – isolated ranked game core

Internal in-memory prototype only. Server catalog snapshot from commit 1977f394b7ca5a7709d5ea048dedd7ad19926610, generated from the existing RAW/RAW2/RAW3/RAW4, ADD, KCH, TEAMS and STARS definitions using the same normalization and merging logic. Test compares the snapshot against the actual trusted static app data; update both intentionally when catalog changes. This is existing app data, not independent factual verification. No data is read from a client at runtime.

Proposed initial rules: 1v1, five fixed rounds, twenty seconds each, server RNG chooses unique playable club pairs; first correct answer wins the difficulty-weighted points. Used footballers cannot score again. Exact normalized canonical names take priority; only globally unambiguous exact aliases are accepted. No fuzzy matching, no jokers/hints, no team selection yet. Wrong answer cooldown 3s, reused player 1.5s. Empty/timeout rounds consume a round; exhausted pool voids match. No client clocks or supplied score. Public-style snapshots omit hidden answers and future pairs. No automatic background timer: trusted caller must tick the game.

IMPORTANT: state is currently in-memory; do not deploy as a live match API. Authenticated request handling, durable state, serialized command execution across isolates, secure creation/completion in D1, verified forfeits/disconnect policy, rate limits, and D1 settlement integration are future stages. Never use host or browser data as authoritative final result. Ranked flag stays off, existing rooms and API version unchanged. Run node --test tests/*.test.cjs with Node 22.13+.
