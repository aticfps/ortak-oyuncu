# V26.1b – Production transport (not activation)

Production Pages must bind RANKED_DB to the verified production D1 instance, and Preview Pages must bind its separate preview D1 instance. This code cannot verify a physical D1 ID by binding name. The production transport is disabled unless RANKED_PRODUCTION_ENABLED is exactly true and RANKED_PRODUCTION_HOST is exactly ortak-oyuncu.pages.dev. Both flags are Production-only; never copy them to Preview. If both preview and production enable flags are true, the transport fails closed. Preview retains its UID allowlist. Production requires a verified Google/Firebase identity and existing registered profile; match participant checks and rate limits remain server-side. No client UI change in this PR. Do not set the production enable flag until UI, regression, quota, cron and deployment checks are complete. Set the production enable flag false and redeploy to disable play; note that disabling while matches are active can interrupt them and the sweeper may resolve abandoned matches. No database reset or copy is required.
